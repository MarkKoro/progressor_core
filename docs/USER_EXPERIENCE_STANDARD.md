# Система удобства Food / Gym Diary / Supply / Общих связей

Версия 1, 13 октября 2026. Основание — [исследование десяти приложений и платформенных правил](QUALITY_RESEARCH.md). Общие связи — пользовательский интерфейс Core внутри трёх продуктов; пользователю не требуется отдельная четвёртая программа или знание слова Core.

## Структура интерфейса

Предметный главный экран показывает сегодняшний результат и одно понятное основное действие. Компактная общая панель отвечает за переходы, подписки и настройки связей. Дневник/история и редактирование имеют предсказуемый возврат. Подсказка относится к текущему действию, раскрывает причину по запросу и умеет скрываться. Общие компоненты используют одинаковые названия, смысл цветов, кнопок, периодов и состояния; сами предметные экраны сохраняют характер Food/Gym/Supply.

Базовые состояния каждого сценария: initial/loading/ready/empty/saving/success/error/stale/noaccess. Нельзя выдавать empty за ошибку, success до подтверждения или noaccess за отсутствие данных. Экран с объяснением содержит действие продолжения/повтора/возврата, соответствующее реальной ситуации.

## Прогонка жизненных сценариев

Каждый вход Food-only/Gym-only/Supply-only → первое добавление → исправление → повтор из истории → связывание/отказ → общая подсказка → настройки/отдых → одиночная/общая подписка → истечение части прав → возврат. Дополнительно все3активны, разныепрофили/вес, coachKBJU/top5, дваGymэкрана и freefinish90min, пропускприёма/напоминания, неполныйдень и неделю, неизвестнаяцель, долгий AI, потерясети/устаревшийотклик/двойнойклик. В каждом случае фиксируем: начало, действие, результат/сохранённые данные, число шагов/сетевых вызовов/AI-вызовов, возможность вернуться, поведениеприотказе.
